# Scraps browser playtest

[Play Scraps](https://kingmadellc.github.io/Scraps/)

This branch contains the browser playtest distribution. Serve the folder over HTTP to run the build locally; opening index.html directly is not a supported WebGL launch path. Build metadata, when present, identifies the release candidate.

Scraps is a prototype. Report reproducible playtest issues without personal information, save exports, or account details. Ongoing source development and large authoring assets are maintained privately; this branch contains selected public runtime output.
