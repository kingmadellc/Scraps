## Authoritative project reference

`Art/References/jimothy-user-primary.png` was supplied by the user after the first prototype. It establishes the high domed back, long thin limbs, lowered small head, short torso and awkward mid-step posture. It overrides the earlier spherical, short-legged interpretation. Running timing is still an interpretation until moving reference is available.

## Ballard

[City of Seattle — Ballard Avenue Landmark District](https://www.seattle.gov/neighborhoods/historic-preservation/historic-districts/ballard-avenue-landmark-district) describes the designated district. [City historic-site record](https://web.seattle.gov/dpd/historicalsite/QueryResult.aspx?ID=2147015919) provides local building context. [University of Washington / MOHAI historical street photograph](https://digitalcollections.lib.washington.edu/digital/collection/imlsmohai/id/15359/rec/1) is a historical reference, not evidence of present-day conditions.

The modeled brick blocks are original procedural approximations. A modern street-level photography/location pass is still needed for authentic facades, signage, proportions, landmark positions and sightlines.

## Image generation

Built-in imagegen was used for the menu concepts. Prompt records are in `Documentation/IMAGE_PROMPTS.md`. The corrected version uses the user's photograph as its identity reference; the initial round short-legged image is superseded. Generated artwork is not a screenshot of the playable game. Both tool outputs were 1672×941 despite requesting larger output; no claim of native 4K is made.

## Additional user references and approved direction

`Art/References/jimothy-running-user.png` shows an extended, uneven mid-bound stride. `Art/References/jimothy-statue-user.png` is a sculpture reference emphasizing the compressed rounded body, low head and bent reaching forelimb. The sculpture informs silhouette, not natural fur color. The user explicitly liked `MenuHero-v2.png`, with the seaplane, and asked that the real Blender model approach that appearance. Earlier Blender passes were rejected; a new pass is an iteration, not implied user approval.
